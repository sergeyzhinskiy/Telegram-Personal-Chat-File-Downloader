#  Telegram Personal Chat File Downloader

Автоматизированный скрипт на Python для резервного копирования и выгрузки документов из всех **личных диалогов (DM)** Telegram-аккаунта. Скрипт скачивает только файлы с разрешенными расширениями, игнорируя групповые чаты, каналы и ботов.

##  Ключевые возможности

*   **Выгрузка из приватных чатов:** Анализирует только диалоги формата «тет-а-тет» (User-to-User). Группы, каналы и боты автоматически фильтруются для экономии трафика.
*   **Фильтрация по расширениям:** Скачивает только целевые рабочие документы (`.pdf`, `.docx`, `.xlsx` и др.). Список расширений легко кастомизируется.
*   **Автономная сессия (Session File):** Авторизация через СМС-код/2FA требуется только при первом запуске. В дальнейшем скрипт использует сохраненный файл сессии.
*   **Безопасное переименование:** Автоматически очищает имена файлов от запрещенных операционной системой символов и генерирует уникальные имена по ID сообщения, если имя файла отсутствует.

##  Подготовка и системные требования

Для работы скрипта требуется **Python 3.8+** и библиотека асинхронного взаимодействия с Telegram API - **Telethon**.

### 1. Установка зависимостей
Установите официальный пакет Telethon через `pip`:
```bash
pip install telethon
```

### 2. Получение Telegram API Ключей
Для авторизации скрипта в Telegram-сети вам необходимо зарегистрировать собственное standalone-приложение:
1. Перейдите на официальный портал разработки: [https://telegram.org](https://telegram.org).
2. Авторизуйтесь под своим номером телефона.
3. Перейдите в раздел **API development tools**.
4. Заполните поля `App title` и `Short name` (можно указать любые значения, например `MyDownloader`).
5. Нажмите **Create application**.
6. Скопируйте полученные значения **App api_id** и **App api_hash**.

##  Конфигурация скрипта

Перед запуском откройте файл `main.py` в текстовом редакторе и отредактируйте блок конфигурации в самом начале файла:

```python
# Конфигурация – замените на свои данные
API_ID = 12345678                  # Вставьте сюда полученный числовой API_ID
API_HASH = '9d41eb3856...'         # Вставьте сюда полученную строку API_HASH
PHONE = '+12345677890'             # Укажите ваш номер телефона в международном формате
```

### Настройка разрешенных типов файлов
Вы можете добавить или удалить форматы документов, отредактировав множество `ALLOWED_EXTENSIONS`:
```python
ALLOWED_EXTENSIONS = {'.pdf', '.doc', '.docx', '.xls', '.xlsx', '.ppt', '.pptx', '.zip', '.rar'}
```

##  Инструкция по запуску

1. Запустите скрипт через терминал или командную строку Windows:
   ```bash
   python main.py
   ```
2. **Первый запуск (Авторизация):**
   * Скрипт запросит код подтверждения. Код придет в ваше **официальное приложение Telegram** (от аккаунта `Telegram`).
   * Введите код в консоль и нажмите `Enter`.
   * Если на вашем аккаунте включена двухфакторная аутентификация (2FA), скрипт дополнительно запросит ваш облачный пароль. Введите его.
3. **Последующие запуски:** Скрипт будет подхватывать сессию из файла `user_session.session` и выполнять выгрузку мгновенно, без повторного ввода кодов.

Все файлы будут сохранены в локальную папку `downloaded_files/`.

##  Безопасность и лимиты Telegram

*   **Защита сессии:** Файл `user_session.session` является вашим постоянным ключом доступа к аккаунту. Никогда не передавайте его третьим лицам и не загружайте в открытые репозитории GitHub. Добавьте его в `.gitignore`.
*   **Ограничения (Flood Wait):** При обработке слишком большого количества чатов или сообщений за один раз Telegram может временно ограничить запросы (ошибка `FloodWaitError`). Библиотека Telethon автоматически обрабатывает такие задержки и ставит скрипт на паузу до снятия ограничений.
